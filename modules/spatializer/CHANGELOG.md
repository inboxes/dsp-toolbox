# Changelog: 3D Spatializer

## [0.1.0] - Unreleased

First release. `minHostVersion` is 0.1.0, the first app version.

### Added

- Up to 8 sources rendered for headphones with Steam Audio, as static sounds, orbits or keyframed paths.
- Near, Mid and Far ranges, with bundled KEMAR and SADIE II HRTF sets. You can add your own in the user data folder.
